ERD: accounts and todos

Two new tables in demo-api's database. Each todo belongs to exactly one user.

Decision to approvetodos.user_id is a foreign key with ON DELETE CASCADE, so deleting a user deletes their todos.
erDiagram
  users ||--o{ todos : owns
  users {
    uuid id PK
    text email UK
    timestamptz created_at
  }
  todos {
    uuid id PK
    uuid user_id FK
    text title
    boolean done
    timestamptz created_at
  }

Why this shape

  • No soft delete yet. Nothing in the PRD needs it.
  • Index on todos(user_id, created_at) for the list query.
